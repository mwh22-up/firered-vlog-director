# 11 支参考 Vlog 学习结论

## 分析范围

- 参考视频：用户指定的 11 支 Bilibili Vlog；
- 总时长：约 148 分钟；
- 自动识别：3,110 个镜头、132 个事件；
- 每支均完成镜头、事件、声场和 faster-whisper ASR 分析；
- 代理、完整逐字稿、模型缓存和事件图片只保存在 `<本机缓存目录>`，不进入 Git；
- 仓库只保存脱敏分析 JSON、量化聚合档案和语义导演档案。

## 稳定的量化规律

| 指标 | 11 支参考片结果 | 对北欧片的含义 |
|---|---:|---|
| 正文镜头时长中位数 | 平均 2.263 秒 | 移动、超市和快速发现段应压缩 |
| 开场前 15 秒平均镜头时长 | 0.983 秒 | 可用 10–15 秒感官预告建立观看承诺 |
| 有效对白保留率 | 98.8% | 完整现场对白不能为了快节奏被切碎 |
| 动作镜头保留率 | 67.5% | 到达、选择、行动、结果应优先保留 |
| 人物反应保留率 | 85.7% | 真实交流和同行反应优先于重复空镜 |
| 细节镜头保留率 | 8.0% | 商品、建筑和景物细节必须提供新信息 |
| 环境建立镜头保留率 | 22.4% | 同类风景只留最能建立空间关系的一条 |
| 平均声场构成 | 环境 49.9%、对白 28.8%、音乐 10.5%、静音 10.9% | 保留真实环境声，不用音乐铺满全片 |

## 不能机械照搬的部分

参考片拥有大量拍摄角度和补充 B-roll，因此能长期维持约 2 秒一镜。北欧素材只有 18 条原始长视频，且用户明确以自然景色和异国风情为核心。如果强行复制参考片节奏，会产生三种问题：

1. 山顶景色失去沉浸感；
2. 现场英文对白被切成残句；
3. 为凑镜头密度而重复放大、裁切同一素材。

因此北欧片采用“功能化节奏”：

- 开场、机场移动、超市观察：1–3 秒一信息点；
- 抵达与上山行动：3–6 秒一动作；
- 山顶全景和环境变化：6–12 秒，允许观众看清空间；
- 完整对白和真实反应：按句子与回答决定长度，不按固定秒数截断；
- 结尾白色街区逐渐降速，不额外制造高潮。

## 应用到北欧项目的导演规则

1. 旅程按“落地北欧 → 生活发现 → 抵达卑尔根 → 上山行动 → 风景回报 → 当地交流 → 城市余韵”组织，不做景点清单。
2. 上山事件必须保留交通铺垫、途中揭示和山顶反应，不能只留漂亮全景。
3. 超市商品只有与价格、选择或人物评价相连时保留。
4. 山顶同类全景去重，但海湾、森林、木屋和城市俯瞰属于不同空间层次，应分别保留。
5. 当地人谈雪、火山和北极光的英文对白属于锁定节点，使用中英双语字幕。
6. 不确认山名，不在字幕或贴图中擅自写 Fløyen、Ulriken 等名称。
7. 无旁白；原声持续托底；当前不增加来源不明的配乐。
8. 字幕和贴图只解释画面无法自行表达的信息，不重复说明显而易见的景色。

## 智能字幕方案

- 输入：每条原片的词级时间戳与 `edit_plan`；
- 映射：把原片时间自动换算到成片时间，剪掉的内容不会生成字幕；
- 分句：遇到 0.65 秒停顿、句末标点、4.2 秒上限或 26 字上限时断句；
- 质量过滤：过滤极低置信词和明显非语音区；
- 边界保护：所有字幕严格裁到所属剪辑片段和成片总时长内；
- 样式：最多两行、底部居中、8% 安全边距、白字深色描边；
- 翻译：关键英文对白保留英文原句，第二行提供中文翻译；听不清的内容不臆造；
- 当前产物：86 条字幕，相邻重叠为 0，增强门禁 0 错误、0 警告。
